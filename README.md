# timefind

A CLI tool for finding files by modification time.

## Features

- [ ] List regular files in a directory
- [ ] Recursive directory traversal
- [ ] Filter files by modification time
- [ ] Move matched files safely 

## Build 

gcc -Wall -Wextra -g main.c -o timefind

## Usage

./timefind ./testdata

## Limitaton

Currently only supports non-recursive directory scanning.
